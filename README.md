# تطبيق تسجيل الطلاب

تطبيق ويب بسيط باستخدام HTML وCSS وPHP وMySQL لتسجيل الطلاب وعرض بياناتهم.

## المميزات
- نموذج تسجيل الطلاب: الاسم والبريد الإلكتروني والرقم الجامعي والقسم.
- تخزين البيانات في MySQL.
- عرض الطلاب المسجلين.
- حذف سجل طالب.
- التحقق الأساسي من صحة النموذج.

## خطوات التشغيل
1. استورد ملف `internship_db.sql` إلى خادم MySQL.
2. حدّث بيانات الاتصال بقاعدة البيانات في `db.php` عند الحاجة.
3. ضع ملفات المشروع في مجلد الخادم، مثل `htdocs` في XAMPP.
4. افتح `index.php` في المتصفح.
